This addon is based on Octowow 25/07/2026.

It replace the yard units with metre units.

The transition from yards to metres is done in real time when you pass over your mouse so Unless you play with 10 FPS, it should feel instant to your eyes.

If you are not using an Addon installer, you will have to create a folder named MetricRange with both files in it and place it in Interface\AddOns.
